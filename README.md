# Yushi & Riku Virtual Phone
Fan-made iOS-inspired virtual phone demo.

## Run
Open `index.html` in a browser, or publish the folder to GitHub Pages.

## Passcode
4503

## Files
- index.html: screens and app markup
- style.css: phone layout and styling
- script.js: clock, passcode, app navigation and demo content
- images/: optional place for your own wallpapers/icons

The Photos app currently uses decorative emoji tiles, not official artist photos. Replace these with images you have permission to use.
